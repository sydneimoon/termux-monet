An unofficial, modified fork of Termux — an Android terminal application and Linux environment — with Material You (Monet) theming, experimental features and community-made changes.

Powerful Features

Everything the regular Termux gives you, plus a Material You touch

Material You Theming

A dynamic Monet color scheme powered by your wallpaper. On Android 12+ the app follows Material You, while lower versions show a static black and white theme.

Experimental Features

A playground of community-made changes and experimental patches on top of Termux. Don't expect consistency, professionality or stability.

Nightly & Stable Builds

Stabler releases from GitHub Releases and bleeding-edge unstable APKs from GitHub Actions, built for every push to the repository.

Security Warning

APK files on GitHub are signed with a test key shared with the community. This is not an official developer key and everyone can use it to forge a malicious Termux update installable over the GitHub build. Think twice before installing Termux builds distributed via Telegram or other social media — this key is easy to detect in user generated content.
